# 🤖 Bots for Discord

Zbiór botów do Discorda.

| Bot | Opis |
|---|---|
| [🛠️ Kreator Serwera](./kreator-serwera) | Jedna komenda `/stworz` otwiera panel z 16 krokami pytań (lub szybki tryb – 4 pytania) i buduje cały serwer: role z uprawnieniami, kategorie i kanały z ustawionym dostępem (kto widzi, kto pisze), regulamin, informacje, weryfikację, AutoMod i tryb Społeczności. Komenda `/usun` czyści serwer (z kopią zapasową do przywrócenia). `/stworz` działa na kody dostępu generowane w konsoli (z pakietami, szablonami i terminem ważności) – do sprzedaży gotowych serwerów; onboarding Discorda, banery, paczka emoji, podgląd obrazkiem, kanały pod popularne boty; po budowie bot nie jest potrzebny. |

Instrukcja instalacji znajduje się w pliku README każdego bota.
